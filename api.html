CourtPulse API

Live, crowd-reported player counts at tennis and pickleball courts. Read-only. Counts only: no names or emails. Version 1.

By using the API you agree to the API Terms of Use. To request a key, contact [contact email].

Basics

Base URLhttps://wjedvyqtqgvclxxsxyox.supabase.co/functions/v1/api
AuthenticationSend your key in the x-api-key header on every request.
Rate limit60 requests per minute per key by default. Every response includes X-RateLimit-Limit and X-RateLimit-Remaining. Over the limit returns 429.
FormatJSON over HTTPS, GET only. Cross-origin requests (CORS) are allowed.
AttributionPlease credit "Data from CourtPulse" with a link to this site.

List parks

GET /v1/parks

ParameterMeaning
sportpickleball (default) or tennis
zip5-digit US ZIP code. Sorts by distance and filters by radius.
lat, lngAlternative to zip.
radiusMiles. Default 10, maximum 50. Used with zip or lat/lng.
limitDefault 50, maximum 100.

Example (macOS, Linux, Windows curl.exe)

curl -H "x-api-key: YOUR_KEY" \
  "https://wjedvyqtqgvclxxsxyox.supabase.co/functions/v1/api/v1/parks?sport=tennis&zip=92880&limit=3"

Example (PowerShell)

Invoke-RestMethod -Uri "https://wjedvyqtqgvclxxsxyox.supabase.co/functions/v1/api/v1/parks?sport=tennis&zip=92880&limit=3" `
  -Headers @{"x-api-key"="YOUR_KEY"} | ConvertTo-Json -Depth 5

Get one park

GET /v1/parks/{slug}?sport=tennis returns a single park with the same fields, without distance_miles.

Reading the numbers

FieldMeaning
avg_playing, avg_waitingAverage of player reports in the last window_minutes (currently 120).
reports_in_windowHow many reports the average is based on. 0 means no recent data: treat the zeros as "unknown", not "empty courts".
max_playing, max_waitingLargest values a player can report: 4 playing and 2 waiting per court.
distance_milesStraight-line distance from the ZIP or coordinates. Only present on the list endpoint with a location.

Counts are reported by players and are approximate. They can be wrong or out of date.
